Geocoding is the process of finding geographic coordinates for a physical address. A pair of coordinates serves to identify a location on Earth's surface.

Coordinates -> Location

Each address may lead to a point, or several, with Latitude (Y-coordinate) and Longitude (X-coordinate), in decimal format. The coordinates use a Reference Coordinate System called WGS 84 (or, sometimes set as EPSG:4326)

## Reversed Geocoding

Kind of exactly what it says on the tin.

~~Geocoding is finding coordinates for a physical location. Reversed geocoding is finding a physical location based on a set of coordinates. Addresses let us physically locate a building, but it differs by country and area.~~

Apparently it's a bit more complicated than that.

Geocoding is finding coordinates for a physical location, that's correct.

Reversed Geocoding, on the other hand, is more like *assigning a name* to a place rather than getting it. It's not really like going to a set of coordinates and finding it called as "sesame street", it's more like going to a set of coordinates and *naming it* "sesame street".


## Latitude and Longitude

These are systems of lines used to describe any location on earth. Latitudes run from east-to-west, while Longitudes run from north-to-south. These lines are imaginary (you might realise you can't see any lines floating across the sky), but they do appear on maps nonetheless.

Longitudes run from -180° to 0° to 180°, with 0° at the Prime Meridian. Note that, for Longitudes, 180° and -180° is the same place. -180° to 0° covers the West side, while 0° to 180° covers the entire East side. 

Latitudes run from -90° to 0° to 90°. Note that for Latitudes, 90° is the North Pole while -90° is the South Pole.
